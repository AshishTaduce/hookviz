# Design reference

`main-visualizer-screen.html` is a static Claude-Design export of the main
HookViz visualizer screen (dark terminal/debugger aesthetic — see
docs/04_handoffs.md section B for the prompts that produced it).

This is a **visual reference, not production code.** Open it in a browser to
see colors, spacing, type scale, and the breadcrumb-popover interaction —
then translate it into real React/Monaco components per docs/02_ui_spec.md.
Do not import or embed this file directly in web/.
